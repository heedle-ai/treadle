Every invariant below is guarded by a test or a CI step, and CI checks this page against the code on every push with `bash .github/invariants.sh`. Only the **Guarded by** column counts. Each test name listed there must exist and pass without being skipped; every guard test in the code must be listed.

[[/images/invariant-loop.svg|alt=From a mistake to a codified invariant: mistake, named invariant, guard, CI gate]]

| ID | Invariant | Guarded by | Came from |
|---|---|---|---|
| TREAD-1 | A skill's front matter follows Anthropic's Agent Skills rules (name of lower-case letters, digits and single hyphens, at most 64; description of 1 to 1024 characters without `<` or `>`), and its folder pirn's (`pirn.CheckSkill`); both are YAML strings, the front matter ends at a line that is exactly `---`, names draft reserves and control characters in descriptions are refused | `TestInv_SkillsAreChecked` | Skills (roadmap 3.4); review 13: `---extra` closed the front matter, numbers passed as names, control characters reached terminals, and skills named `par` could never be called |
| TREAD-2 | Each version of a skill is a commit on `refs/treadle/skills/<name>` whose tree is the folder byte for byte; adding the same folder again changes nothing; every version stays readable | `TestInv_LibraryKeepsEveryVersion` | Skills (roadmap 3.4) |
| TREAD-3 | A skill named like a command is left out, not fatal; a plan's pins must be versions added to the skill they're named as (never just any tree in the store with that `SKILL.md`), one version per skill | `TestInv_PinsAreChecked`, `TestInv_UnknownVersionsFailAsSetup` | Skills (roadmap 3.4); review 13: an agent's `/work/out` could mint a pinnable "version", and one bad skill stopped every worker |
| TREAD-4 | A run using a skill is checked against, runs with and is recorded with the version its plan pins, even after the skill changes; a fresh compile pins the newest | `TestLaw_SkillRunsArePinned` | Skills (roadmap 3.4): the same program compiles differently once a skill changes |
| TREAD-5 | A skill step whose version isn't in the library, or is another skill, fails with `SkillSetup`, non-retryable, before any container starts | `TestInv_UnknownVersionsFailAsSetup` | Skills (roadmap 3.4) |
| TREAD-6 | Getting Started's clone loop names exactly this repo and every sibling `go.mod` builds against | `TestInv_GettingStartedClonesEverySibling` | Carried over from pirn, where the list fell behind |
| TREAD-7 | The private repos bobbin, reed and pirn are checked out with their own read-only deploy keys; a missing key fails CI rather than skipping | `ci:private-bobbin`, `ci:private-reed`, `ci:private-pirn` | treadle builds against them |
| TREAD-8 | A skill ref whose newest version isn't a valid skill of its name is left out and reported; the others are still listed | `TestInv_BrokenSkillsAreSkipped` | Review 13: one such ref made every listing, worker and drawdown fail |
| TREAD-9 | Writers adding the same folder at once all get the same version, and one commit | `TestInv_ConcurrentAddsAgree` | Review 13: seven of eight concurrent adds failed with a conflict |
| TREAD-10 | A skill imported from a Git folder is that folder's files exactly (hidden ones left out), and its version's commit names the repository, ref, folder and exact source commit, which `Skills` and `Versions` read back; importing again gives the same version | `TestInv_ImportsKeepTheirSource` | Importing skills (roadmap 3.5) |
| TREAD-11 | A source must be an `https://` or `file://` URL, a plain branch or tag, and a safe relative path, refused before git runs; a missing folder, a symbolic link or an invalid skill is refused, and nothing is kept | `TestInv_ImportsAreChecked` | Importing skills (roadmap 3.5): a URL like `--upload-pack=…` must never reach git as an option |
| TREAD-12 | A GitHub link to a repository, or to one of its folders at a branch or tag, is read as a source, with or without a trailing slash; anything else isn't | `TestInv_GitHubLinks` | Importing skills (roadmap 3.5); building it: a trailing slash stayed in the path |
| TREAD-13 | A catalog lists every folder up to three levels down with a `SKILL.md`, with its name and description, or why it can't be imported as it is | `TestInv_CatalogListsARepositorysSkills` | Importing skills (roadmap 3.5) |
