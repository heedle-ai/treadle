# treadle

Skills for heedle-ai: folders whose `SKILL.md` says how to do a kind of work, kept in Git and turned into commands. A program says `(weather "Boston")`; its plan pins the skill's exact version; the step runs as a Claude agent step with the skill in its container; the run's record keeps the version.

See the [wiki](https://github.com/heedle-ai/treadle/wiki): [Getting Started](docs/wiki/Getting-Started.md), [How It Works](docs/wiki/How-It-Works.md), [Invariants](docs/wiki/Invariants.md).
